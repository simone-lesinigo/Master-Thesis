# 🎓 Master's Thesis in Computer Science

This repository contains my Master's thesis: "**On Using Wave Function Collapse for Depicting Software Systems**", developed as part of the **Double Degree Program** between the **Master's Degree in Computer Science** at the Università degli Studi di Milano-Bicocca (UniMiB) and the **Master's Degree in Informatics** at Università della Svizzera italiana (USI).

The thesis explores the use of **Wave Function Collapse (WFC)** for software system visualization, combining **Multidimensional Scaling (MDS)** for class placement with WFC for generating relationship paths.

The research resulted in a peer-reviewed paper presented at [VISSOFT 2026](https://vissoft.io/2026/index.html), NIER Track.
