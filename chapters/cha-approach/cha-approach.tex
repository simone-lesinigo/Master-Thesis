\chapter{From Code to Visualization}
\label{chap:approach}

In this chapter, we present the methodology implemented in \wassis to address the two challenges introduced in \secref{sec-intro:problem_statement}: how to place software entities on a canvas and how to display their relationships.

\wassis is a prototype developed in Pharo that implements the complete pipeline, from the source code to generating and rendering the final visualization.

The pipeline of our approach, illustrated in \figref{fig:approach_flow}, consists of four main phases:
\begin{enumerate}
    \item \textbf{Initialization}: Parsing the source code to extract entities (classes) and their dependencies, initializing an empty grid.
    \item \textbf{Layout via MDS}: Computing a distance matrix based on structural relationships, then applying Multidimensional Scaling (MDS) to position the classes on the grid.
    \item \textbf{Path Generation via WFC}: Defining path tiles and leveraging Wave Function Collapse (WFC) to procedurally generate paths between the placed classes.
    \item \textbf{Finalization}: Computing quantitative metrics and rendering the final visualization.
\end{enumerate}
