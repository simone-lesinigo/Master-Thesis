\chapter{From Code to Visualization}
\label{chap:approach}

In this chapter, we present how \wassis combines Multidimensional Scaling (MDS) and Wave Function Collapse (WFC) to position software entities on a canvas and draw the relationships between them while preserving connectivity and reducing visual clutter.

The proposed approach consists of four main phases, illustrated in  \figref{fig:approach_flow}:
\begin{enumerate}
    \item \textbf{Initialization}: Parsing the source code to extract entities (classes) and their dependencies, initializing an empty grid.
    \item \textbf{Layout via MDS}: Computing a distance matrix based on structural relationships, then applying Multidimensional Scaling to position the classes on the grid.
    \item \textbf{Path Generation via WFC}: Defining path tiles and leveraging Wave Function Collapse to procedurally generate paths between the placed classes.
    \item \textbf{Finalization}: Computing metrics such as path length and edge crossings for the evaluation of the resulting visualization, and rendering the final result.
\end{enumerate}
