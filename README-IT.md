# 🎓 Tesi di Laurea Magistrale in Informatica

Questo repository contiene la mia tesi di Laurea Magistrale: **"On Using Wave Function Collapse for Depicting Software Systems"**, sviluppata nell'ambito del **Programma di Doppia Laurea** tra il **Corso di Laurea Magistrale in Informatica** presso l'Università degli Studi di Milano-Bicocca (UniMiB) e il **Master in Informatics** presso l'Università della Svizzera italiana (USI).

La tesi esplora l'utilizzo di **Wave Function Collapse (WFC)** per la visualizzazione di sistemi software, combinando **Multidimensional Scaling (MDS)** per il posizionamento delle classi con WFC per la generazione dei percorsi delle relazioni.

La ricerca ha portato alla pubblicazione di un articolo scientifico, presentato a [VISSOFT 2026](https://vissoft.io/2026/index.html), NIER Track.
